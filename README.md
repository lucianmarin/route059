## Route 138 (Sans-Serif)

- **Role:** Proportional sans-serif typeface.
- **Primary inspiration:** Route 159.
- **Distinctive character:** Incorporates the best letter shapes from **Vegur** (the earlier predecessor to Route 159) so Route 138 stands apart from Route 159 while retaining its humanist/geometric clarity.
- **UPM:** 1000 (matching Route 159 & Vegur)
- **Vertical metrics (target, based on Route 159):**
  - `hhea` Ascent / Descent / LineGap: `970` / `-230` / `0`
  - `OS/2` TypoAscender / TypoDescender / TypoLineGap: `770` / `-230` / `100`
  - `OS/2` WinAscent / WinDescent: `970` / `230`
  - Cap Height: `740`
  - x-Height: `520`
- **Glyph set:** 565 glyphs (553 Unicode codepoints) — Route 159's 346-glyph core plus Latin-1/Extended-A completions, print punctuation, currency, fractions, superscripts/subscripts, core math operators, and core arrows from Hack.
- **Styles:** Regular, Bold, Italic, Bold Italic (4 styles).
- **Output format:** OTF (CFF) in `dist/`.
- **Vegur-inspired letterforms adopted** (scaled/harmonized to Route 159's metrics and italic angle):
  - `g` (single-story)
  - `J` (descending tail)
  - `Q` (curved tail)
  - `R` (curved leg)
  - `K`, `k` (humanist join)
  - `a` (softer bowl)
  - `t` (curved foot)
  - `y` (curved tail)
  - `1`, `4` (humanist numerals)
  - `&` (humanist ampersand)
  - `?` (fluid curve)

## Route 038 (Monospace)

- **Role:** Code-editor-ready monospace companion to Route 138.
- **Design process (Hack-first):** Built directly on **Hack**'s proven monospace foundation (preserving Hack's stroke weight, rhythm, `0O1lI` legibility, punctuation, and terminal glyphs), subsetted to ~720 usable Latin/coding/terminal glyphs, and infused with **Route 138 / Vegur's signature humanist letterforms** (`g`, `a`, `k`, `t`, `y`, `J`, `Q`, `R`, `K`, `4`, `&`, `?`) scaled to Hack's exact x-height (`1120`) and cap-height (`1493`).
- **Exact metric compatibility with Hack:** Matches Hack's proven code-editor cell width and vertical metrics:
  - **UPM:** `2048` (matching Hack exactly so advance width `1233` is an exact integer without rounding drift)
  - **Advance width (all glyphs):** `1233`
  - **Cap Height:** `1493`
  - **x-Height:** `1120`
  - **`hhea` Ascent / Descent / LineGap:** `1901` / `-483` / `0`
  - **`OS/2` TypoAscender / TypoDescender / TypoLineGap:** `1556` / `-492` / `410`
  - **`OS/2` WinAscent / WinDescent:** `1901` / `483`
- **Glyph set:** 732 glyphs (720 Unicode codepoints) — all 565 Route 138 glyphs plus terminal-only Box Drawing (128), Block Elements (32), and Powerline PUA (7) glyphs pulled 1:1 from Hack.
- **Styles:** Regular, Bold, Italic, Bold Italic (4 styles, matching Hack).
- **Output format:** OTF (CFF) in `dist/`.

## Morphing & Style-Transfer Algorithm (`scripts/morph_svg.py`)

Both families are generated by morphing upright **Regular** and **Bold** Bézier outlines (`Route 159 + Vegur → Route 138` at `α = 0.50`, and `Hack + Route 138 → Route 038` at `α = 0.45`), then deriving **Italic** and **Bold Italic** afterward via a `12°` oblique shear pivoted at half x-height (`y = 260` for Route 138, `y = 560` for Route 038, keeping Box Drawing / Block Elements / Powerline glyphs upright).

Each glyph pair goes through the following stages:

1. **Contour Pairing:** Contours are paired by `(outer/hole winding role, nearest centroid)` after horizontal center-alignment so multi-counter glyphs (`B`, `8`, `=`) never swap counters.
2. **Automatic Topology-Mismatch Guard:** Computes the max unit-box normalized Chamfer distance across outer contours and relative inner-counter positions (`_max_chamfer_distance > 0.09`).
   - **Compatible topologies** proceed to shape morphing (steps 3–7).
   - **Incompatible topologies** (e.g., Hack's serifed `I`/`i`/`l`/`1` or fused monospace `@` vs. Route 138's sans/open-loop forms) automatically use **topology-preserving style transfer** (`style_transfer_contours`):
     - *Gentle 2D proportion warp (FFD)* toward the partner's vertical/horizontal landmarks while preserving baseline and monospace centering.
     - *Anisotropic H/V contrast transfer* matching the partner's separate vertical stem (`w_v`) and horizontal bar (`w_h`) weights.
     - *Curve-tension transfer* applying subtle superellipse squaring on curved non-corner spans.
3. **Corner-Anchored DP Alignment (`morph_pair_smart`):** Detects sharp corners (`k = 1`, `angle_thresh = 0.50`), aligns them via circular Needleman-Wunsch dynamic programming, and interpolates each span by local arc length.
   - *Unmatched-corner damping:* Spans with unmatched base corners damp `α` to prevent half-melted serifs.
   - *Area-preservation guard:* Falls back to uniform arc-length morphing if the morphed contour area collapses below `65%` of the smaller source (preventing self-crossing on `Q`, `8`).
4. **Rigid Straight-Span Stroke Equalization (`equalize_stroke_weight`):** Measures local stroke thickness along inward normals toward the base glyph's median stem weight. Straight spans between corners offset rigidly by their interior median shift and meet at exact geometric line intersections so T-junctions (`4`, `H`, `T`, `t`) never flare or pinch.
5. **Volume-Preserving Taubin Fairing (`taubin_fair_contour`):** Smooths non-corner interior points while pinning sharp corners and their immediate neighbors.
6. **Shared-Corner H/V Snapping & Cubic Bézier Refitting (`contours_to_svg_path`):** Snaps near-horizontal/vertical straight spans (`≤ 3.5°`) consistently on shared corner coordinates, and refits curved spans with Schneider's least-squares cubic Bézier fitter (handle length clamped to `0.65 × seg_len` to prevent loops).

## Build Pipeline (SVG-First)

Run the entire 5-step pipeline with:
```bash
./scripts/pipeline.sh
```

1. **Step 1 (`export_sources_svg.py`):** Export upright `Regular` and `Bold` source SVGs from `inspiration/` into `svg/{route159,vegur,hack}/`.
2. **Step 2a (`extend_vegur.py`):** Extend `svg/vegur/` to match the exact 334-glyph set of `svg/route159/`.
3. **Step 2b (`reshape_r138.py`):** Morph `Route 159 + Vegur → svg/route138/{Regular,Bold}/`, then derive `12°` oblique `Italic` and `BoldItalic`.
4. **Step 3a (`extend_route138.py`):** Extend `svg/route138/` to cover 100% of `svg/hack/` (composing accented Latin from Route 138 + scaling remainder from Hack) and mirror into `Italic`/`BoldItalic`.
5. **Step 3b (`reshape_r038.py`):** Morph `Hack + Route 138 → svg/route038/{Regular,Bold}/`, then derive `12°` oblique `Italic` and `BoldItalic` (keeping Box Drawing, Block Elements, and Powerline upright).
6. **Step 4a / 4b (`build_r138.py`, `build_r038.py`):** Compile SVGs directly to OTF (CFF) fonts in `dist/`.
7. **Step 5 (`build_repr_svg.py`):** Compose pure-vector specimen posters (`route138-repr.svg`, `route038-repr.svg`) directly from `sample.txt` and the generated glyph SVGs.

Outputs are written to `dist/`:
- `Route138-Regular.otf`, `Route138-Bold.otf`, `Route138-Italic.otf`, `Route138-BoldItalic.otf`
- `Route038-Regular.otf`, `Route038-Bold.otf`, `Route038-Italic.otf`, `Route038-BoldItalic.otf`
